Windows Agent Deployment

Follow these steps to deploy the Windows agent for naXtra Pulse IR System:

  1. Download the Windows agent package: windows_agent.zip
  2. Extract the zip to your desired location on the Windows host.
  3. Open PowerShell as Administrator.
  4. Run the install script: install.ps1
  5. The agent will start sending logs to the naXtra Pulse IR server.
